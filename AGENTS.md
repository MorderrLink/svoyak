# Правила работы с проектом «Свояк»

## Обязательные технические правила

- Проект использует TypeScript в строгом режиме.
- Не добавляйте `any` без явного обоснования в комментарии и описании задачи.
- Не смешивайте серверный и клиентский код. Клиентские модули с директивой
  `"use client"` не должны импортировать `src/server/`.
- Общие типы, Zod-схемы и Socket.IO-контракты размещайте в `src/shared/`.
- Все входные данные HTTP API, Socket.IO, файлов и переменных окружения должны
  проверяться через Zod до использования.
- Игровое состояние изменяет только сервер. Клиенты отправляют намерения и
  отображают полученное состояние.
- Не отправляйте игрокам или публичному экрану приватный комментарий ведущего,
  правильный ответ до раскрытия и управляющие токены.

## Интерфейс и стили

- Страницы не должны иметь общей прокрутки документа.
- Корневой layout сохраняет `height: 100dvh` и `overflow: hidden`.
- Прокрутка допускается только внутри компонента `ScrollArea` или другой явно
  ограниченной области.
- Основные стили создаются через Tailwind CSS.
- Нестандартные стили нижнего прогресс-бара находятся только в
  `src/styles/bottom-progress.css`.
- Не используйте внешние шрифты, CDN и обязательные внешние API: приложение
  должно работать без интернета.

## Проверки и документация

- После каждой задачи запускайте `npm run check`.
- Для изменений production-сборки дополнительно запускайте `npm run build`.
- Для пользовательских сценариев добавляйте или обновляйте Playwright-тесты.
- Не изменяйте `docs/SPECIFICATION.md` без явного решения пользователя.
- При изменении архитектуры или поведения обновляйте соответствующую
  документацию.
- Каталог `games/` содержит пользовательские данные и не должен
  форматироваться или индексироваться линтером.
