# Проверка версии 1.0

## Автоматические проверки

Перед коммитом:

```bash
npm run check
npm run build
npm run test:e2e
```

`check` последовательно запускает строгий TypeScript, ESLint, проверку
Prettier и Vitest. Unit- и integration-тесты проверяют схемы, библиотеку,
ZIP/integrity, игровые фазы, переходы между раундами, rate limit, Socket.IO и
границы client/server. Playwright проводит двухраундовую игру, проверяет
приватность публичного экрана, переподключение, таблицу тем и цен, состояния
кнопки игрока, изображения, загрузку и обрезку аудио, управление
воспроизведением, экспорт и повторный импорт.

Chromium для первого E2E-запуска:

```bash
npx playwright install chromium
```

## Проверка production-запуска

```bash
npm run build
npm start
```

В консоли должны появиться режим `production`, путь `games` и локальные URL.
Откройте главную страницу, библиотеку и создание комнаты. После сборки
отключите внешний интернет и повторите загрузку: шрифты, QR-код, стили,
изображения, аудио, видео и Socket.IO должны продолжить работать.

## Матрица интерфейсов

Проверьте отсутствие прокрутки всего документа и доступность внутренних
`ScrollArea`:

- 320 × 568;
- смартфон 390 × 844;
- планшет 768 × 1024;
- ноутбук 1366 × 768;
- телевизор 1920 × 1080;
- масштаб браузера 80%, 100%, 125% и 200%.

Отдельно используйте имя игрока из 20 символов, отрицательный счёт, длинную
тему и вопрос, вертикальное и горизонтальное изображения.

## Финальный локальный прогон

Требуется ручной прогон на реальном оборудовании:

1. компьютер ведущего и телевизор/проектор в одной LAN;
2. минимум пять телефонов;
3. викторина минимум из двух раундов;
4. текстовые вопросы, изображения, аудио, видео и их сочетания с текстом;
5. правильные, неправильные ответы и повторное открытие кнопок;
6. отключение и переподключение одного телефона;
7. завершение всех раундов и проверка итоговой таблицы;
8. экспорт ZIP, удаление викторины и импорт этого ZIP.

Этот аппаратный прогон нельзя заменить браузерной автоматизацией. Найденные
блокирующие ошибки исправляются до создания тега `1.0.0`.
