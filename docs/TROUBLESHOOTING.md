# Диагностика «Свояка»

## Сервер не запускается

- Для production-режима сначала выполните `npm ci`, затем `npm run build` и
  только после этого `npm start`.
- Проверьте Node.js: требуется версия 20.9 или новее.
- Если порт занят, запустите сервер с другим портом:
  `PORT=4000 npm start`.
- При первом запуске должны создаться `games/` и `games/assets/`. Сообщение
  «каталог недоступен для записи» означает, что нужно перенести проект в
  доступное место, исправить права или освободить диск.

## Игрок не открывает страницу

- Компьютер ведущего и телефон должны быть в одной Wi-Fi или LAN-сети.
- На телефоне временно отключите мобильный интернет и VPN.
- Используйте адрес из блока «Диагностика сети» панели ведущего, а не
  `localhost`.
- Проверьте, что firewall разрешает входящие подключения Node.js к выбранному
  порту.
- В гостевой Wi-Fi-сети отключите client isolation или изоляцию клиентов.

## Socket.IO не подключается

Проверьте индикатор Socket.IO, выбранный интерфейс, порт и количество клиентов
в панели ведущего. После краткого обрыва страница переподключается
автоматически.

## Комната пропала

Активные комнаты хранятся только в памяти. После остановки или перезапуска
сервера ведущему нужно создать новую комнату, а игрокам — подключиться к
новому коду.

## Ошибки библиотеки и медиа

Сообщения `QUIZ_STORAGE_ERROR` различают отсутствие прав, read-only файловую
систему, нехватку места и ошибки ввода-вывода. Не редактируйте JSON во время
работы приложения. Отсутствующий ассет возвращает понятную ошибку и не
завершает сервер. Аудио и видео обрабатываются поставляемыми с npm-пакетами
FFmpeg/FFprobe. Если обработка не запускается, переустановите зависимости
через `npm install` для текущей операционной системы и архитектуры.

Перед редактированием или копированием содержимого `games/` остановите сервер.

## Где находится журнал игры

События записываются в `games/.sessions/logs/YYYY-MM-DD.jsonl`. Каждая строка
— самостоятельный JSON-объект. Секретные host/player token в журнал не
записываются.
