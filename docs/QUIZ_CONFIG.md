# Формат конфигурации викторины

## Версия 1

`schemaVersion: 1` описывает обратно совместимый формат викторины. В версии
приложения 0.3 содержимое вопроса может включать текст, изображение или оба
поля. Экспортируемый ZIP дополнительно содержит манифест целостности.

```json
{
  "schemaVersion": 1,
  "id": "00000000-0000-4000-8000-000000000001",
  "title": "Кино 2026",
  "slug": "kino-2026",
  "settings": {
    "questionIntroSeconds": 2.5,
    "buzzSeconds": 10,
    "answerSeconds": 15,
    "answerRevealSeconds": 5,
    "allowNegativeScore": true,
    "showScoresToPlayers": true
  },
  "rounds": [
    {
      "id": "00000000-0000-4000-8000-000000000002",
      "order": 0,
      "themes": [
        {
          "id": "00000000-0000-4000-8000-000000000003",
          "title": "Кино",
          "order": 0,
          "questions": [
            {
              "id": "00000000-0000-4000-8000-000000000004",
              "price": 100,
              "content": {
                "text": "Назовите актёра.",
                "image": {
                  "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000005.webp",
                  "alt": "Кадр из фильма"
                }
              },
              "answer": "Киану Ривз",
              "hostComment": "Можно принять только имя и фамилию"
            }
          ]
        }
      ]
    }
  ],
  "packageIntegrity": {
    "algorithm": "sha256",
    "assets": [
      {
        "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000005.webp",
        "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
        "size": 12345
      }
    ],
    "contentDigest": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb"
  },
  "createdAt": "2026-07-29T18:00:00.000Z",
  "updatedAt": "2026-07-29T18:01:00.000Z"
}
```

## Правила

- `schemaVersion` для текущего формата строго равен `1`.
- Идентификаторы викторины, раундов, тем и вопросов являются UUID и уникальны
  во всём конфиге.
- Раунды не имеют пользовательского названия.
- `order` раунда или темы совпадает с индексом элемента в соответствующем
  массиве и начинается с нуля.
- Сохранённая викторина содержит минимум один раунд, тему и вопрос.
- `content` содержит непустой текст, изображение или оба поля.
- Путь изображения имеет вид `assets/<slug>/images/<safe-name>` и не может
  ссылаться на другой каталог.
- Правильный ответ не может быть пустым.
- Стоимость является положительным целым числом и уникальна внутри темы.
  Разные темы могут использовать одинаковые стоимости.
- `slug` содержит только строчные латинские буквы, цифры и одиночные дефисы.
- `createdAt` и `updatedAt` записываются в ISO 8601; `updatedAt` не может быть
  раньше `createdAt`.
- Неизвестные поля отклоняются.

`packageIntegrity` обязателен внутри экспортируемого ZIP. Для старых локальных
конфигов без пакета поле остаётся необязательным и создаётся сервером при
экспорте. Манифест содержит отсортированные пути, размеры, SHA-256 файлов и
`contentDigest` канонизированного конфига.

Черновик редактора может временно быть неполным. Перед сохранением он должен
быть преобразован в `QuizConfig` и успешно проверен через
`quizConfigSchema`.
