# Формат конфигурации викторины

## Версия 1

`schemaVersion: 1` описывает обратно совместимый формат викторины. В версии
приложения 1.0 вопрос может включать текст и один тип медиа: изображение,
аудио или видео. Экспортируемый ZIP дополнительно содержит манифест
целостности.

```json
{
  "schemaVersion": 1,
  "id": "00000000-0000-4000-8000-000000000001",
  "title": "Кино 2026",
  "slug": "kino-2026",
  "settings": {
    "questionIntroSeconds": 2.5,
    "buzzSeconds": 10,
    "answerSeconds": 15,
    "answerRevealSeconds": 5,
    "allowNegativeScore": true,
    "showScoresToPlayers": true
  },
  "rounds": [
    {
      "id": "00000000-0000-4000-8000-000000000002",
      "order": 0,
      "themes": [
        {
          "id": "00000000-0000-4000-8000-000000000003",
          "title": "Кино",
          "description": "Назовите фильм по описанию сцены.",
          "order": 0,
          "questions": [
            {
              "id": "00000000-0000-4000-8000-000000000004",
              "price": 100,
              "content": {
                "text": "Назовите актёра.",
                "image": {
                  "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000005.webp",
                  "alt": "Кадр из фильма"
                }
              },
              "answer": "Киану Ривз",
              "answerImage": {
                "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000006.webp",
                "alt": "Портрет Киану Ривза"
              },
              "hostComment": "Можно принять только имя и фамилию"
            }
          ]
        }
      ]
    }
  ],
  "packageIntegrity": {
    "algorithm": "sha256",
    "assets": [
      {
        "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000005.webp",
        "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
        "size": 12345
      },
      {
        "path": "assets/kino-2026/images/00000000-0000-4000-8000-000000000006.webp",
        "sha256": "cccccccccccccccccccccccccccccccccccccccccccccccccccccccccccccccc",
        "size": 23456
      }
    ],
    "contentDigest": "bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb"
  },
  "createdAt": "2026-07-29T18:00:00.000Z",
  "updatedAt": "2026-07-29T18:01:00.000Z"
}
```

## Правила

- `schemaVersion` для текущего формата строго равен `1`.
- Идентификаторы викторины, раундов, тем и вопросов являются UUID и уникальны
  во всём конфиге.
- Раунды не имеют пользовательского названия.
- Тема может содержать непустое пояснение `description` длиной до 5000
  символов. Ведущий показывает его публичному экрану перед вопросами темы.
- `order` раунда или темы совпадает с индексом элемента в соответствующем
  массиве и начинается с нуля.
- Сохранённая викторина содержит минимум один раунд, тему и вопрос.
- `content` содержит непустой текст либо один тип медиа. Допустимы `text`,
  `image`, `media` и сочетание текста ровно с одним из них. Одновременные
  `image` и `media` запрещены.
- Аудио хранится как `media.kind: "audio"`, WebM/Opus, длительность, границы
  обрезки и waveform из 120 значений. Видео хранится как `kind: "video"`,
  MP4/H.264, длительность и границы обрезки.
- `trimStartMs < trimEndMs <= durationMs`; максимальная длительность — 30
  минут, максимальный исходный или нормализованный файл — 200 МБ.
- Путь изображения имеет вид `assets/<slug>/images/<safe-name>` и не может
  ссылаться на другой каталог.
- Правильный ответ содержит непустую строку `answer`, `answerImage` или оба
  поля. Поэтому допускается ответ только с изображением.
- Стоимость является положительным целым числом. Вопросы внутри темы могут
  иметь одинаковую стоимость: их порядок определяется позицией в массиве.
- `slug` содержит только строчные латинские буквы, цифры и одиночные дефисы.
- `createdAt` и `updatedAt` записываются в ISO 8601; `updatedAt` не может быть
  раньше `createdAt`.
- Неизвестные поля отклоняются.

`packageIntegrity` обязателен внутри экспортируемого ZIP. Для старых локальных
конфигов без пакета поле остаётся необязательным и создаётся сервером при
экспорте. Манифест содержит отсортированные пути, размеры, SHA-256 файлов и
`contentDigest` канонизированного конфига. Полная структура архива и этапы
проверки описаны в [PACKAGE_FORMAT.md](PACKAGE_FORMAT.md).

Черновик редактора может временно быть неполным. Перед сохранением он должен
быть преобразован в `QuizConfig` и успешно проверен через
`quizConfigSchema`.
