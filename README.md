# Свояк

Локальное многопользовательское веб-приложение для создания и проведения
викторин. Компьютер ведущего запускает единый Next.js и Socket.IO сервер, к
которому устройства подключаются в общей локальной сети.

## Требования

- Node.js 20.9 или новее;
- npm 11 или совместимая версия;
- общая локальная сеть для компьютера ведущего и устройств игроков.

## Установка

```bash
npm ci
npm run build
```

Установка зависимостей требует доступа к npm или заранее заполненного
npm-кэша. После установки и сборки приложение не обращается к CDN и внешним
API и работает без интернета.

## Запуск

Для обычной игры запускайте production-сервер:

```bash
npm start
```

При первом запуске приложение создаст `games/` и `games/assets/`, проверит
возможность записи и выведет адреса в консоль. На компьютере ведущего
открывайте `http://localhost:3000`, на телефонах и телевизоре — один из
адресов вида `http://192.168.x.x:3000`. Другой порт:

```bash
PORT=4000 npm start
```

Режим разработки запускается командой `npm run dev`.

## Создание викторины

1. Откройте `/library` и нажмите «Создать викторину».
2. Укажите название, настройки времени и правила показа баллов.
3. Добавьте раунды, темы и вопросы. Вопрос может содержать текст и один тип
   медиа: изображение, аудио или видео; ответ и комментарий ведущего не
   показываются игрокам.
4. Сохраните викторину. JSON появится в `games/`, изображения — в
   `games/assets/<slug>/images/`, аудио и видео — в
   `games/assets/<slug>/media/`.

Поддерживаются JPEG, PNG, WebP и GIF до 10 МБ. Сервер проверяет фактическое
содержимое файла, ограничивает разрешение и сохраняет нормализованный WebP.
Аудио и видео до 200 МБ и 30 минут нормализуются локальным FFmpeg; из видео
можно автоматически извлечь звуковую дорожку.

## Проведение игры

1. В библиотеке нажмите «Создать комнату» у нужной викторины либо откройте
   `/host` и выберите её.
2. В центральном лобби игроки сканируют QR-код или открывают `/join`, вводят
   четырёхзначный код и имя. Ведущий видит время подключения, доступное
   браузеру название устройства, ping и онлайн-статус. После старта вход новых
   игроков закрывается, но переподключение уже вошедших продолжает работать.
3. Нажмите «Открыть публичный экран», перенесите окно на телевизор или
   проектор и при необходимости включите полноэкранный режим.
4. Запустите викторину и выберите вопрос. Нажатия игроков появятся на карточках
   в панели ведущего: число в кружке показывает порядок. Нажмите карточку
   игрока, которому разрешаете отвечать. В игровой боковой панели имя и баллы
   каждого игрока сопровождаются зелёным или красным индикатором подключения.
5. Оцените ответ большой кнопкой ✓ (`V`) или ✕ (`X`). В окне баллов клавиши
   `↑` и `↓` меняют сумму на 100, `S` меняет знак, `0` обнуляет, `X` умножает
   на два, а `Enter` подтверждает. `Space` пропускает активный таймер ведущего.
   Стрелки рядом с номером раунда позволяют свободно переходить между
   раундами, не сбрасывая сыгранные вопросы и баллы.
6. Перед изменением счёта проверьте предложенные баллы и подтвердите операцию.
   После неправильного ответа очередь и номера нажатий сохраняются. Ошибившийся
   больше не выбирается и видит красную кнопку до конца вопроса.
   Кнопка «Никто не ответил» предложит списать стоимость вопроса с каждого
   игрока; списание также применяется только после подтверждения ведущего.
7. После последнего раунда приложение покажет итоговую таблицу.

В лобби, на сетке и после завершения игры ведущий может нажать карточку игрока
и вручную скорректировать его счёт. Во время вопроса эта операция недоступна.
После оценки ответа кнопка игрока показывает не только результат, но и
фактически начисленную или снятую сумму.

Обновление страницы безопасно для ведущего и игроков, пока сервер продолжает
работать: роль и актуальное состояние восстанавливаются из памяти процесса.
После остановки или перезапуска сервера активные комнаты удаляются.

Панель ведущего `/host/[roomCode]` содержит правильный ответ, приватный
комментарий, историю попыток и управление. Публичный экран
`/display/[roomCode]` показывает лобби, таблицу вопросов, вопрос, отвечающего
игрока и раскрытый ответ. Имена со счётом игроков на этот экран не передаются.
Он не получает токен ведущего, приватный комментарий и правильный ответ до
фазы раскрытия.

Игрок может нажимать кнопку касанием, мышью, `Space` или `Enter`.

## Экспорт и импорт

В библиотеке нажмите «Экспорт ZIP» и сохраните архив. Для переноса на другой
компьютер скопируйте ZIP, откройте там библиотеку и выберите «Импортировать
ZIP». Архив содержит конфиг, только используемые изображения и
SHA-256-манифест. При конфликте slug интерфейс предложит заменить викторину
или создать независимую копию. Подробности — в
[PACKAGE_FORMAT.md](docs/PACKAGE_FORMAT.md).

## Сетевые проблемы

Если телефон не открывает адрес, отключите на нём VPN и мобильный интернет,
проверьте firewall компьютера и запрет изоляции клиентов в гостевой Wi-Fi.
Используйте LAN-адрес из панели ведущего, а не `localhost`. Полная памятка
находится в [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

## Команды

```text
npm run dev          разработка через собственный сервер
npm run build        production-сборка Next.js
npm start            запуск production-сервера после сборки
npm run typecheck    проверка TypeScript
npm run lint         проверка ESLint
npm run format       форматирование проекта
npm run format:check проверка форматирования
npm test             unit- и компонентные тесты
npm run test:e2e     Playwright-тесты
npm run check        все обязательные проверки этапа
```

Для первого E2E-запуска может потребоваться локальная установка Chromium:

```bash
npx playwright install chromium
```

диагностику. Основные сценарии проверяются unit, integration и
