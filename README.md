# Свояк

Локальное многопользовательское веб-приложение для создания и проведения
викторин. Компьютер ведущего запускает единый Next.js и Socket.IO сервер, к
которому устройства подключаются в общей локальной сети.

## Требования

- Node.js 20.9 или новее;
- npm 11 или совместимая версия;
- общая локальная сеть для компьютера ведущего и устройств игроков.

## Установка и запуск

```bash
npm install
npm run dev
```

По умолчанию приложение доступно на `http://localhost:3000`. Сервер также
выводит доступные локальные IPv4-адреса. Другой порт можно задать переменной:

```bash
PORT=4000 npm run dev
```

## Media and Package Beta

После запуска:

1. Откройте `/library` и создайте викторину.
2. Добавьте раунды, темы и вопросы, настройте таймеры и сохраните изменения.
   К вопросам можно загружать JPEG, PNG, WebP и GIF: сервер проверит
   содержимое и нормализует его в WebP.
3. Нажмите «Создать комнату» в карточке викторины либо откройте `/host` и
   выберите викторину из списка.
4. Выберите подходящий локальный адрес рядом с QR-кодом.
5. Игроки сканируют QR-код или открывают `/join` и вводят код комнаты.
6. После подключения игроков ведущий запускает сессию и выбирает вопрос в
   игровой сетке.
7. Ведущий оценивает ответ, при необходимости редактирует изменение баллов и
   подтверждает его. После неверного ответа кнопки автоматически открываются
   для остальных игроков.

В библиотеке доступны «Экспорт ZIP» и «Импортировать ZIP». Архив содержит
конфиг, только используемые изображения и SHA-256-манифест. При конфликте slug
можно заменить существующую викторину или создать независимую копию.

Игрок может нажимать кнопку касанием, мышью, `Space` или `Enter`. Токен игрока
сохраняется в браузере и используется для восстановления после обновления
страницы.

## Команды

```text
npm run dev          разработка через собственный сервер
npm run build        production-сборка Next.js
npm start            запуск production-сервера после сборки
npm run typecheck    проверка TypeScript
npm run lint         проверка ESLint
npm run format       форматирование проекта
npm run format:check проверка форматирования
npm test             unit- и компонентные тесты
npm run test:e2e     Playwright-тесты
npm run check        все обязательные проверки этапа
```

Для первого запуска E2E-тестов может потребоваться локальная установка
Chromium:

```bash
npx playwright install chromium
```

## Статус

Завершена версия 0.3 Media and Package Beta. Работают текстовые вопросы и
вопросы с изображениями, безопасное хранилище `games/assets`, предпросмотр и
alt-текст, перенос assets при смене slug, строгий ZIP export/import,
SHA-256/contentDigest, защита от опасных путей и ZIP Bomb, транзакционный
импорт и разрешение конфликтов. Комнаты находятся в памяти и исчезают после
перезапуска сервера; викторины и изображения сохраняются локально.

Полные требования находятся в [спецификации](docs/SPECIFICATION.md), порядок
работ — в [плане](docs/PLAN.md), архитектурные границы — в
[ARCHITECTURE.md](docs/ARCHITECTURE.md), а текстовый формат викторины — в
[QUIZ_CONFIG.md](docs/QUIZ_CONFIG.md).
