# Свояк

Локальное многопользовательское веб-приложение для создания и проведения
викторин. Компьютер ведущего запускает единый Next.js и Socket.IO сервер, к
которому устройства подключаются в общей локальной сети.

## Требования

- Node.js 20.9 или новее;
- npm 11 или совместимая версия;
- общая локальная сеть для компьютера ведущего и устройств игроков.

## Установка и запуск

```bash
npm install
npm run dev
```

По умолчанию приложение доступно на `http://localhost:3000`. Сервер также
выводит доступные локальные IPv4-адреса. Другой порт можно задать переменной:

```bash
PORT=4000 npm run dev
```

## Release Candidate

После запуска:

1. Откройте `/library` и создайте викторину.
2. Добавьте раунды, темы и вопросы, настройте таймеры и сохраните изменения.
   К вопросам можно загружать JPEG, PNG, WebP и GIF: сервер проверит
   содержимое и нормализует его в WebP.
3. Нажмите «Создать комнату» в карточке викторины либо откройте `/host` и
   выберите викторину из списка.
4. Выберите подходящий локальный адрес рядом с QR-кодом.
5. Игроки сканируют QR-код или открывают `/join` и вводят код комнаты.
6. После подключения игроков ведущий запускает сессию и выбирает вопрос в
   игровой сетке.
7. Нажмите «Открыть публичный экран», перенесите новое окно на телевизор или
   проектор и при необходимости включите полноэкранный режим.
8. Ведущий оценивает ответ, при необходимости редактирует изменение баллов и
   подтверждает его. После неверного ответа кнопки автоматически открываются
   для остальных игроков.

Обновление страницы безопасно для ведущего, игроков и публичного экрана:
роль и актуальное состояние восстанавливаются с сервера. Активные комнаты
периодически сохраняются в `games/.sessions/active-rooms.json` и
восстанавливаются после перезапуска приложения. Токены в snapshot записываются
только как SHA-256-хеши.

Панель ведущего работает по адресу `/host/[roomCode]` и содержит правильный
ответ, приватный комментарий, историю попыток и управляющие действия.
Публичный экран `/display/[roomCode]` подключается к серверу самостоятельно и
показывает лобби, игровую сетку, вопрос, отвечающего игрока, раскрытый ответ и
итоговую таблицу. Он не получает токен ведущего, приватный комментарий и
правильный ответ до фазы раскрытия.

В библиотеке доступны «Экспорт ZIP» и «Импортировать ZIP». Архив содержит
конфиг, только используемые изображения и SHA-256-манифест. При конфликте slug
можно заменить существующую викторину или создать независимую копию.

Игрок может нажимать кнопку касанием, мышью, `Space` или `Enter`. Токен игрока
сохраняется в браузере и используется для восстановления после обновления
страницы. Кнопка «Эффекты» включает локальный звук открытия кнопок, звук
победы и вибрацию поддерживаемого телефона.

Панель ведущего содержит блок диагностики локальной сети: состояние
Socket.IO, количество подключений, локальные IPv4, выбранный адрес и порт, а
также подсказки по Wi-Fi, VPN, firewall и client isolation. Журнал игры
записывается в `games/.sessions/logs/*.jsonl` и не содержит секретных токенов.

## Команды

```text
npm run dev          разработка через собственный сервер
npm run build        production-сборка Next.js
npm start            запуск production-сервера после сборки
npm run typecheck    проверка TypeScript
npm run lint         проверка ESLint
npm run format       форматирование проекта
npm run format:check проверка форматирования
npm test             unit- и компонентные тесты
npm run test:e2e     Playwright-тесты
npm run check        все обязательные проверки этапа
```

Для первого запуска E2E-тестов может потребоваться локальная установка
Chromium:

```bash
npx playwright install chromium
```

## Статус

Завершена версия 0.5 Release Candidate. Активные комнаты, фазы, баллы,
сыгранные вопросы и операции баллов восстанавливаются после перезапуска.
Таймеры сохраняют абсолютное время и не запускаются повторно после обновления
страниц. Добавлены rate limit на сокет и игрока, cooldown, отключение
нарушителей, журнал событий без секретов, диагностика сети, понятные файловые
ошибки и локальные аудио/виброэффекты. Основные сценарии проверяются unit,
integration и Playwright-тестами, включая приватность display, переподключение
ролей и комнату с 20 игроками.

Полные требования находятся в [спецификации](docs/SPECIFICATION.md), порядок
работ — в [плане](docs/PLAN.md), архитектурные границы — в
[ARCHITECTURE.md](docs/ARCHITECTURE.md), а текстовый формат викторины — в
[QUIZ_CONFIG.md](docs/QUIZ_CONFIG.md). Решения сетевых и файловых проблем
собраны в [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
